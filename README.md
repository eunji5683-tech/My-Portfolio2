# 포트폴리오 2

바이브코딩으로 만든 프로젝트 3개를 한곳에 모아 보여주는 **포트폴리오 메인 페이지**예요.
HTML, CSS, JavaScript만 사용했고 별도 설치 없이 브라우저에서 바로 열려요.

## 보여주는 프로젝트
| 카드 | 설명 | 누르면 |
|---|---|---|
| **홍보자동생성기** | 매장 사진을 인스타 크기로 바꾸고 로고를 넣고, 가게 말투로 홍보 문구까지 만들어 주는 도구 | 이 포트폴리오 안의 **결과물 소개 페이지**(`promo.html`) |
| **메뉴보드** | 손님이 QR을 찍어 휴대폰으로 보는 디지털 메뉴판 | 메뉴판 앱 화면 (또는 GitHub 저장소) |
| **적립스탬프** | 번호 뒤 4자리로 스탬프를 찍는 단골 적립 웹앱 | 적립스탬프 앱 화면 (또는 GitHub 저장소) |

- 홍보자동생성기: [auto-generate-app](https://github.com/eunji5683-tech/auto-generate-app)
- 메뉴보드: [Menu-board-app](https://github.com/eunji5683-tech/Menu-board-app)
- 적립스탬프: [Stamp-plus-app](https://github.com/eunji5683-tech/Stamp-plus-app)

## 디자인
**그라데이션 리얼리즘** 스타일이에요.
- 맑고 가벼운 바탕 위에, 빛과 그림자가 있는 3D 느낌의 구슬(구)과 코일(스프링)이 떠 있어요.
- 구슬과 코일은 이미지가 아니라 CSS와 JavaScript로 그렸어요.
- 마우스를 움직이면 구슬이 살짝 따라 움직이고, 카드에 올리면 살짝 기울어요.
- 휴대폰에서는 카드가 한 줄로 쌓이고, 기기에서 "움직임 줄이기"를 켜 두면 움직이는 효과를 꺼요.

## 파일 구성
| 파일 | 설명 |
|---|---|
| `index.html` | 메인 페이지 (프로젝트 카드 3개) |
| `style.css` | 모든 디자인 (메인 페이지와 소개 페이지) |
| `main.js` | 카드 주소 연결, 코일 그리기, 마우스 움직임 |
| `promo.html` | 홍보자동생성기 결과물 소개 페이지 (사진, 문구, 만드는 방법) |
| `promo.js` | 소개 페이지의 문구 탭, 복사하기 버튼, 사진 크게 보기 |
| `promo/` | 소개 페이지에 쓰는 사진 4장 |

## 보는 방법
`index.html`을 더블클릭하면 브라우저에서 열려요.

## 카드 연결 주소 바꾸는 법
`main.js` 맨 위의 `PROJECTS`와 `USE_LOCAL_LINKS`에서 바꿔요. 한국어 설명이 달려 있어요.

- `USE_LOCAL_LINKS = true`: 메뉴보드와 적립스탬프 카드가 **내 컴퓨터에 있는 앱 화면**을 열어요. 이 폴더 옆에 `메뉴판`, `단골 적립 스탬프` 폴더가 나란히 있을 때만 돼요.
- `USE_LOCAL_LINKS = false`: 두 카드가 **GitHub 저장소 주소**로 가요. 어디서 열어도 돼요.
- 나중에 GitHub Pages 같은 진짜 사이트 주소가 생기면 `PROJECTS`의 `github` 자리에 그 주소를 넣으세요.
- 홍보자동생성기 카드는 항상 `promo.html`로 가요.

## 홍보 문구와 사진 바꾸는 법
- 문구: `promo.js` 맨 위의 `STYLES`에서 글자를 고쳐요.
- 사진: `promo/` 폴더의 사진 파일을 바꾸거나, `promo.html`에서 사진 파일 이름을 바꿔요.

## ⚠️ 알아둘 점
- 이 저장소를 **인터넷 사이트(GitHub Pages)**로 열면, 메뉴보드와 적립스탬프 카드는 `USE_LOCAL_LINKS`가 `true`일 때 열리지 않아요. 사이트로 올릴 때는 `false`로 바꾸거나 각 앱의 사이트 주소를 넣으세요.
- 홍보자동생성기 소개 페이지의 문구에는 가게 이름과 위치가 들어 있어요.

## 사용한 것
HTML, CSS, JavaScript만 사용했어요. 리액트 같은 복잡한 도구는 쓰지 않았어요.
